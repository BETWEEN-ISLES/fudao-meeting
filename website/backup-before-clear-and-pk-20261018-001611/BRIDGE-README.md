# 遊戲 2：方塊搭橋

入口為 `bridge.html`，飛行遊戲頁下方也有遊戲切換。

## 玩法

棋盤為 6 欄 × 7 列。每次從三個候選四格方塊中選一個，自由放置在棋盤，沒有重力。可以按旋轉或 R 改變方向，點擊棋盤或直接拖曳候選方塊放置。預覽格是方塊的左上角。

放置後即補入一個新候選方塊。從底部任一格到頂部任一格，以上下左右相接形成連續路線，就立即通關、標示路線並結算。斜角接觸不算。

當三個候選方塊的所有旋轉方向都無法放下時，遊戲結束。遊戲中可以撤回一步；撤回會同步恢復棋盤、分數與候選方塊。

## 計分

- 放置一塊：40 分。
- 每填滿一橫排：150 分，不消除，只計一次。
- 同次填滿多排：第二排起每排額外加 100 分。
- 成功搭橋：500 分。
- 通關時每剩一空格：10 分。
- 未通關仍結算放置與橫排分數；最高通關分數僅存於本機瀏覽器。
