# 作品展覽內頁

從 `index.html` 的「進入浮島」前往 `works.html`。

## 分區與數量

- 影像放映（18 組）：2D 14、3D 2、紀錄片 1、自媒體電影製作 1。
- 多元創作（14 組）：遊戲設計 4、虛擬偶像 1、視覺小說 1、互動設計 3、論文 1、電子繪本 4。

## 填入作品

`works-data.js` 管理所有作品資料；目前的名稱、介紹、視覺與影片均明確標示待公布，並非真實作品素材。組別編號為各類別內暫用編號。

在此檔案底部依範例，以固定 ID 填入 `title`、`description`、`poster` 與 `trailer`。例如 `2d-01`、`game-01`、`book-04`。

建議將素材放在本資料夾的 `media/`：海報使用 16:9 JPG/WebP；預告片使用瀏覽器可播放的 MP4（H.264/AAC）。`trailer` 填影片檔路徑，不能直接填 YouTube 網頁網址。保留原有實體資料夾結構，並將新增的內頁檔案一起上傳。

每張卡片展示預告封面與介紹；點擊「進入放映室」後顯示放大的影片播放器並開始播放；若瀏覽器限制播放，會提示觀眾按播放鍵。列表不會同時載入或播放 32 支影片。無影片時顯示準備中；載入失敗時顯示錯誤訊息。

## 檢查

- 全部作品 32 張，10 個類別的篩選數量正確。
- 進入與關閉放映室、Esc 關閉、恢復原捲動位置與鍵盤焦點。
- 手機單欄、平板雙欄、大螢幕三至四欄。
- 真實素材補齊後，仍需檢查影片播放、聲音與海報。
