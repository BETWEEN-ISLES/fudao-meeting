# 浮島飛行

首頁「進入浮島」開啟詢問框：是 → `works.html`；否 → `flight.html`。Esc／關閉按鈕會留在首頁。JavaScript 不可用時，原入口仍可直接前往作品展。

## 操作

- 按開始飛行後，點擊遊戲畫面、手機輕觸、空白鍵或向上鍵振翅；放開自然下降。
- 從上下浮島的縫隙間通過，每通過一組加一分。
- 碰到浮島岩石或畫面上下邊界會結束，按重新挑戰再玩。
- P／暫停按鈕可暫停；切換分頁或視窗會自動暫停。
- 畫面尺寸改變時會重設本局，以避免橫直轉向造成不公平的碰撞。
- 最高分僅儲存在同一瀏覽器，不是線上排行榜。

## 角色

使用專案原有 `image/` 裡三張 PNG 的副本，放在 `website/assets/flight/`：

- `flap.png`：振翅上飛的可愛鳥羽精靈。
- `glide.png`：黑底飛行小鳥人角色插畫（圖檔本身有透明通道）。
- `fallen.png`：透明背景的昏倒羽翼小鳥人。

原始素材保留，未更動或重新生成。浮島、雲層與遠景由遊戲繪製，不依賴外部圖片服務。
