# 8×8、無限模式與手機控制

## 方塊搭橋

單人及同機雙人棋盤均為 8 欄 × 8 列，原電腦的選塊、鍵盤移動、旋轉及放置操作保留。

「無限模式」從 `bridge.html?mode=endless` 進入，或由單人頁上方的模式選單切換。不限時，搭橋成功獲得獎勵後自動換空棋盤；若已無處可放，也會換空棋盤繼續，累計分數保留。「結算本次」才結束。單人通關與無限累積紀錄分開保存。

手機從候選區拖曳方塊，方塊以實際棋盤格大小抬到手指上方跟隨，棋盤同步標示落點。放開後放置；若放在棋盤外則取消，若重疊或越界則顯示錯誤回饋。拖曳靠近螢幕上下緣會自動捲動，方便從候選區拖到棋盤。手機不提供旋轉，無處可放的判定也只計算當前方向。雙人頁在手機改為上下兩個棋盤，各自支援觸控拖曳；電腦仍為左右棋盤與兩組鍵盤。

## 飛行遊戲

支援觸控 PointerEvent，並提供 touchstart 相容處理；滑鼠按鍵檢查只套用在滑鼠，不阻擋觸控。開始後可點擊畫面或底部「振翅」按鈕。

手機不強制聚焦 canvas，也不因視窗 blur 單獨中斷遊戲；實際切到背景時仍會自動暫停。畫面尺寸變動保留分數與本局進度；方向大幅改變時暫停，按繼續即可。
