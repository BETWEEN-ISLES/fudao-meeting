# 浮島之間：森光與夜映

依使用者提供的三張動畫截圖，從「林間日光、夜色紫光、溫暖逆光」提取配色方向。以下為設計選色，並非逐像素抽樣。

| 顏色 | 色碼 | 用途 |
| --- | --- | --- |
| 深森林綠 | `#254C3C` | 日間標題、主要文字 |
| 葉影綠 | `#7F9E69` | 裝飾與光紋，避免作為小字 |
| 溪水青 | `#5F9796` | 背景、拖尾的藍綠層次 |
| 日光奶油白 | `#F4F1E4` | 網頁底色、卡片閱讀區 |
| 暖陽金 | `#C5A56C` | 路牌與互動光澤，避免作為小字 |
| 夜林靛藍 | `#171C32` | 劇院底色 |
| 月光柔紫 | `#B7A3CE` | 劇院標籤、邊緣與操作提示 |

首頁以日間森林為主，加入奶油色光感；路牌用葉綠、溪水青與暖沙金區別三場展覽。作品列表使用暖白底與深綠文字，正式海報及影片不套用濾鏡。進入放映室才切換成靛藍與柔紫。

滑鼠拖尾保留原本路徑與淡出行為，改用溪水青到葉綠的速度變色，邊緣以淡金作光澤。

`forest-theme.css` 統一管理介面色彩，載入順序在既有樣式之後，不改動版面。`script.js` 另管理 WebGL 色彩。兩頁 HTML 需一併上傳，才能載入新主題。
